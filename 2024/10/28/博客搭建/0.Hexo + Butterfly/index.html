Hexo + Butterfly 搭建博客

Hexo 是一个基于 Node.js 的静态博客框架，可以直接使用 Markdown 编写文章，再由 Hexo 生成对应的静态网页。

Butterfly 是 Hexo 的一个主题，在 Hexo 的基础上提供了文章目录、暗色模式、代码块、侧边栏、访问统计等功能，同时也方便继续通过 CSS 和 JavaScript 做自定义。
