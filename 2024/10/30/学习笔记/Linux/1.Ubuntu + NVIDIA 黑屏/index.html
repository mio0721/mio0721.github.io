Ubuntu NVIDIA 显卡导致的黑屏问题

在带 NVIDIA 独显的电脑上安装 Ubuntu 时，可能会遇到系统卡在 Ubuntu Logo、无法进入安装界面或桌面的情况。

常见表现主要有两种：

  • 安装 Ubuntu 时，启动后一直停在 Ubuntu Logo，无法进入安装界面。
  • Ubuntu 已经安装完成，但开机后仍然卡在 Logo，无法进入登录界面。

这类问题可能和 Ubuntu 默认加载的 nouveau 开源显卡驱动有关。
