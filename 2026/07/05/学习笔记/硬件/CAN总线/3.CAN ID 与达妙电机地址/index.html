CAN ID 与达妙电机地址：CAN_ID、Master ID 和模式偏移

学习达妙电机的 CAN 协议时，很容易把 CAN ID、设备地址、CAN_ID 和 Master ID 混在一起。

这一节重点梳理这些概念，以及说明书中常见的 0x01、0x101 和 0x201 分别是怎么得到的。

它并不等同于严格意义上的设备地址。CAN 协议本身关注的是“这是什么消息”，至于某个 ID 是否对应某台电机，由设备厂商设计的上层协议决定。

因此，在达妙电机的控制场景中，可以先把 CAN_ID 理解为电机接收控制命令时使用的编号。

CAN ID 也参与仲裁

CAN 总线上可能有多个节点同时尝试发送数据。标准 CAN 使用非破坏性位仲裁机制决定谁先发送。

在其他条件相同的情况下，数值更小的 CAN ID 通常具有更高优先级。例如 0x100 与 0x200 同时竞争总线时，0x100 会获得更高优先级。

因此 CAN ID 既是消息标识符，也会影响实时通信中的发送优先级。

ID 与工作模式必须对应

并不是向同一台电机随意发送 0x001、0x101 或 0x201 都会得到相同结果。驱动器本身还有当前工作模式，报文 ID、DATA 格式和驱动器配置必须相互匹配。

调试时至少要同时确认：

  • 电机的 CAN_ID
  • Master ID 或反馈 ID 配置
  • 当前控制模式
  • 标准帧或扩展帧设置
  • CAN 波特率
  • 协议版本和固件版本

简单总结，CAN_ID 可以看作达妙电机接收控制命令的编号，Master ID 用于组织反馈消息；而最终出现在总线上的 CAN ID，还可能叠加控制模式偏移。理解这一点后，再看到 0x01、0x101 和 0x201 就不会把它们当成三台不同的电机。
