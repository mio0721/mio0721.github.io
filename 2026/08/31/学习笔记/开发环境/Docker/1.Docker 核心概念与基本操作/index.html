Docker 入门：核心概念与基本操作

Docker 是一种容器化技术。它把程序、依赖和运行配置组织成可重复使用的环境，使同一个项目在开发电脑、测试环境和服务器上更容易保持一致。

一个 Python 项目可能依赖特定版本的 Python、系统动态库、第三方包和环境变量。直接换一台电脑运行时，常见问题包括版本不同、依赖缺失和配置不一致。Docker 的作用，就是把这些运行条件明确地描述并封装起来。

容器和虚拟机有什么区别

传统虚拟机通常包含完整的客户操作系统和内核，而容器更接近一组经过隔离的进程。多个 Linux 容器通常共享宿主机内核，但拥有各自的文件系统视图、网络、环境变量和资源限制。

对比项 Docker 容器 虚拟机
操作系统内核 通常与宿主机共享 每台虚拟机包含自己的客户内核
启动速度 通常较快 通常较慢
资源占用 相对较小 相对较大
隔离方式 进程、文件系统和网络隔离 完整操作系统级虚拟化
常见用途 开发环境、服务部署 完整系统环境、强隔离场景

Docker Desktop、Engine 和 CLI

这几个名称很容易混淆：

  • Docker Engine：负责管理镜像、容器、Volume 和网络的核心服务；
  • Docker CLI：也就是终端中的 docker 命令，用来向 Engine 发送指令；
  • Docker Desktop：Windows 和 macOS 上的桌面管理工具，集成或管理 Engine、CLI、Compose、虚拟化后端和图形界面。
